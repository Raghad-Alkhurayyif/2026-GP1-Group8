# Ma’ta

## Introduction

Ma’ta is an AI-based Android healthcare decision-support application designed to help users make more informed decisions about when and where to seek medical care. Users can describe their symptoms in natural language, and the system identifies possible medical conditions, assesses the urgency of the case, and recommends an appropriate healthcare service. Ma’ta is intended to support healthcare decision-making and does not provide a definitive diagnosis or replace professional medical consultation.

## Technologies Used

- Flutter
- Dart
- Python
- Firebase
- Machine Learning
- Natural Language Processing (NLP)
